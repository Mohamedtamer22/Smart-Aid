# Figma specification

Create Figma pages: `01 Cover`, `02 Problem`, `03 Personas`, `04 User Flows`, `05 Information Architecture`, `06 Design System`, `07 Components`, `08 User App`, `09 Volunteer App`, `10 EMS App`, `11 Smart ER`, `12 Admin`, `13 Accessibility`, `14 States`, `15 Prototype`, and `16 Developer Handoff`.

Use primary blue `#1769AA`, emergency red `#D92D20` only for SOS/critical states, success `#12B76A`, warning `#F79009`, background `#F8FAFC`, text `#101828`, and gray `#667085`. Spacing is 4/8/12/16/20/24/32/40; standard cards use 16px radius. Use Cairo or equivalent Arabic UI typography with Display 32, H1 28, H2 22, H3 18, body 16, caption 13, and button 16.

Prototype the implemented SOS confirmation and confirmed/failed states first. Every design screen must include loading, empty, error, offline, permission-denied, location-unavailable, and session-expired variants. The Smart ER design must say “Recommended destination”, “Decision support”, and “Based on available data”; it must not make a guarantee.
